# 💱 CurrencyExchange - Using API Connection

A real-time Currency Exchange application that fetches live exchange rates using a public API and converts currencies instantly.

---

## 🚀 Features

- 🌍 Real-time currency exchange rates
- 🔄 Convert between multiple currencies
- ⚡ Fast API integration
- 💻 Clean and responsive UI
- 🔐 Secure API request handling
- 📱 Mobile-friendly design

---

## 🛠️ Tech Stack

### Frontend:
- HTML
- CSS
- JavaScript
  

### API Used:
- Exchange Rate API / Open Exchange Rates API


## 🔧 How It Works

1. User selects base currency.
2. User selects target currency.
3. User enters amount.
4. Application sends API request.
5. API returns real-time exchange rate.
6. Converted amount is displayed instantly.
